How the numbers get here

A figure on this site travels from an audited annual report into a workbook, and from the workbook onto a page. This is what happens at each step, and what stops the build when one of them goes wrong.

From the annual report, never the press release

Results day brings a press release, and the press release is written to be quoted. It rounds, it picks its own subtotals, and it leads with whichever number moved the right way. None of it is used here. Every figure starts in the audited annual report, gets keyed into the workbook for its industry, and is restated there onto the same basis as its peers.

Nothing reaches a page by being typed into it. The site reads every number out of the workbook when it builds, so the page and the model cannot disagree.

Every figure is found by its label

A workbook changes between builds. Rows get inserted, sections move, a line gets split in two. A site that went looking for a row number would find whatever had slid into that row and publish it with full confidence.

So the site never asks for a position. It addresses each figure by the label it carries in the workbook, the words in the left-hand column, and finds it wherever that label now sits.

A missing label stops the build

Before it writes a sector's pages, the build checks every label it publishes against every company's sheet. If one no longer resolves, because it was renamed or its section was removed, the build stops and names what it could not find. It does not fall back to the old position, and it does not guess at the nearest match.

The publish step will not run on a failed build. A wrong number is worse than a missing page, so the site takes the missing page.

The sentences answer to the same rule

The prose carries numbers too, and a sentence typed once does not update itself when the model does. So a passage never states a model figure as typed text. It holds a placeholder that the build fills from the workbook, and the build fails on any passage that writes the number in by hand.

Comparisons get the same treatment. When a sentence says a company earns the widest spread or carries the highest cost of capital, the build checks that it still does. Every link to the workings has to land on a table in the data appendix. If either stops being true, the build stops before the page goes out.
